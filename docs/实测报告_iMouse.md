## ⚠️ 风险留痕（先读这段）

源项目 `core/devices/frame_source.py` 文件头的取帧源矩阵原文：

```
| 方式           | 画质         | 痕迹 | 状态     |
|----------------|--------------|------|----------|
| 摄像头         | 有反光/畸变  | 零   | 当前在用 |
| HDMI 采集卡    | 像素级清晰   | 极低 | 计划接入 |
| ADB / WDA      | -            | 高   | **禁用** |
| 投屏 / 镜像    | -            | 高   | **禁用** |
后两者 iOS 上或不可用、或会被 App 检测（用户实测原测算软件因此被封）。
```

iMouse 正是靠 **AirPlay 镜像**工作，等于主动踩了这条红线。
**这是唯一可能让整个项目白干的风险点**，需用户显式确认已评估。
