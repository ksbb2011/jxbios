# 新电脑环境安装配置（2026-09-13 整理）

> 适用：把这套机器人搬到一台**新的 Windows 电脑**。
> 配套文档：`docs\新电脑_校准指南.md`（搬完要重做哪些标定）。
> 校准工具已随包交付：**`校准工具.exe`**（控制台菜单，源码版是 `标定工具.bat`）。

---

## 0. 先看结论（30 秒）

有两条路，**任选一条**：

| | A. exe 路线（推荐） | B. 源码路线 |
|---|---|---|
| 新电脑装 Python？ | **不用** | 要，Python **3.11.x 64 位** |
| 拷什么 | `dist\运满满抢单机器人\` **整个文件夹** | 整个仓库 + `install.bat` |
| 装依赖 | 不用（`_internal` 自带，含 VC 运行库） | 双击 `install.bat` 一键装 + 自检 |
| 能改代码？ | 只能改 `config\*.json` 与 `tools\*.py` | 都能改 |
| 体积 | 约 312 MB | 约 320 MB（含 Python 环境） |

**两条路都必须安装的三个外部组件**（见第 1 节）：iMouse 专业版、JxbService、手机端投屏 + 运满满 App。

## 1. 三条必须的外部组件（装一次，之后不用管）

### 1.1 iMouse 专业版（提供"手机投屏画面"）

| 项 | 说明 |
|---|---|
| 安装位置 | `D:\iMousePro`（本机实测路径，换机器路径可不同） |
| 关键程序 | `iMouseManager.exe`（控制台，需**以管理员身份运行**）、`iMouseSrv.exe`（后台服务） |
| 必须状态 | 控制台里**手机投屏处于在线**，程序读的就是这块画面 |
| 自检命令 | `校准工具.exe imouse`（探版本 / 端口 / 分辨率 / 截图耗时 / 帧率 / 插件），源码版 `py -3.11 tools\imouse_probe.py --repeat 30` |
| 报告位置 | 源码版会写 `docs\实测报告_iMouse.md` |

> 画面规格：iPhone X **375 × 812 逻辑点**。项目里所有模板、归一化 ROI、字段偏移都基于这个坐标空间。

### 1.2 JxbService（机械臂串口服务宿主）

| 项 | 说明 |
|---|---|
| 作用 | 机械臂通过它对外提供 HTTP 接口 |
| 占用资源 | 串口 **COM4** + 本机 HTTP **8082** |
| 接口地址 | `http://127.0.0.1:8082/MyWcfService/getstring`（`config\hardware.json` 可改） |
| 重启命令 | `Restart-Service JxbService -Force`（需管理员，工具里会自动弹 UAC 提权） |
| ⚠️ 已知坑 | 标定进程被**强杀**（Ctrl+C / 崩溃 / 任务管理器结束）后不会执行 `close_port`，服务会一直占着 COM4，下次 `open_port` 返回**资源号 0**（连不上）→ **必须重启服务**才能恢复。校准工具已内置自动重启。 |

### 1.3 手机 + 运满满 App

- iPhone X，App 里登录好司机账号；投屏保持在线。
- 页面由人工摆好（标定工具会提示每个目标的前置条件）。

## 2. A 路线：exe 交付（推荐）

### 2.1 新电脑要"装"什么

**只装第 1 节那三个外部组件**。程序本体不需要安装：

- ✅ 不需要装 Python
- ✅ 不需要装 VC++ 运行库（包内已自带**唯一一套**，见 `installer\打包与交付说明.md` 约定 4）
- ✅ 不需要装任何 pip 包

### 2.2 要"拷"什么

把**整个文件夹** `dist\运满满抢单机器人\` 拷到新电脑（U 盘 / 网盘 / 局域网均可），例如放到 `D:\运满满抢单机器人\`。

> ⚠️ **不要只拷 exe**。这个文件夹里的每一块都有用：
>
> | 内容 | 少了会怎样 |
> |---|---|
> | `运满满抢单机器人.exe` | 主程序（GUI） |
> | `校准工具.exe` | 标定 / 探活工具菜单（控制台） |
> | `_internal\` | 依赖与模型（约 305 MB），**少了直接起不来** |
> | `config\` | 业务配置（路线/阈值/标定参数），**少了会弹窗并退出** |
> | `data\templates\` | 识别模板图，**少了识别全废** |
> | `tools\` | 标定脚本本体（可编辑，改完存盘即生效） |
> | `启动.bat` | 便捷启动器 |

### 2.3 首次启动验证（3 条判据）

1. 双击 `运满满抢单机器人.exe`（或 `启动.bat`）→ 过一次 UAC → GUI 出现。
2. 界面顶部**不应出现**红色「⚠ OCR 引擎未加载」。
3. 打开 `data\gui_boot.log`（首次运行自动生成），确认三行：
   - ① VC 运行库预载**全部 OK**，路径都在 `_internal\` 根
   - ② 全包同名运行库扫描**只有 4 个**（`msvcp140 / msvcp140_1 / vcruntime140 / vcruntime140_1`），且 `PyQt5\Qt5\bin` 下 0 个
   - ③ `onnxruntime: IMPORT_OK`

再点一次界面上的「截图留存」→ 图应落在 `data\shots\`，画面应是**正的 375×812**（歪的或尺寸不对 → 看第 4 节）。

## 3. B 路线：源码交付

### 3.1 装 Python

装 **Python 3.11.x（64 位）**，安装界面**务必勾选**：

- ☑ `Add python.exe to PATH`
- ☑ `py launcher`

装完开新命令行验证：`py -3.11 --version` 应输出 `Python 3.11.x`。

### 3.2 拷代码 + 一键装依赖

1. 把整个仓库拷到新电脑，例如 `D:\robot_order_picker_imouse\`。
2. 双击仓库根目录的 **`install.bat`**：校验 Python → 升级 pip → 按 `requirements.txt` 装依赖 → **逐包 import 自检（含 OCR 链）**。
   - 网络慢就双击命令行执行：`install.bat mirror`（走清华镜像）。
   - 依赖清单与锁定版本见仓库根 `requirements.txt`（版本是实测可用组合，**别随手升级**）。
3. 手动自检（随时可跑）：`py -3.11 tools\check_deps.py`
   - 缺什么：`py -3.11 tools\check_deps.py --install`

### 3.3 启动

- 跑程序：双击 `启动GUI.bat`
- 做标定：双击 `标定工具.bat`（菜单含：归位 / 测下压 / 映射标定 / 复检 / 单步探针 / iMouse 探活 / **UI 落点校准**）

## 4. 端口 / 服务 / 权限速查

| 项 | 值 / 命令 |
|---|---|
| 机械臂 HTTP | `http://127.0.0.1:8082/MyWcfService/getstring` |
| 机械臂串口 | `COM4`（`config\hardware.json` → `calibration.arm_range` / `robot` 段可查） |
| 重启串口服务 | `Restart-Service JxbService -Force`（管理员；被强杀后必须做） |
| 主程序权限 | 启动弹一次 UAC（写 `config\`、`data\` 与访问设备需要） |
| 校准工具权限 | **不提权**（标定要反复跑）；只有重启 JxbService 那一下由工具自己弹 UAC |
| 取帧源 | `config\vision.json` → `capture.source`（本项目为 `imouse`）；`capture.capture_resolution` 与 `fast_size` 都应是 `[375, 812]` |
| 运行日志 | `data\logs\run_*.log`、`data\gui_boot.log` |
| 落点测量记录 | `data\ui_tap_calib.json`（UI 落点校准工具写入，只测量不改配置） |

## 5. 常见故障对照表

| 现象 | 先看哪里 | 处理 |
|---|---|---|
| 双击 exe 没反应 / 立刻退出 | `data\gui_boot.log` | 多数是 `config\` 或 `data\templates\` 没拷全（GUI 用 `ConfigStore(strict=True)`，缺 json 直接退出） |
| 顶部红色「⚠ OCR 引擎未加载」 | `data\gui_boot.log` 的 ③ 行 | 若是 `IMPORT_FAIL` + 「初始化例程失败」→ VC 运行库冲突，按 `installer\打包与交付说明.md` 约定 4 重打；若是「找不到模型」→ 包内 `_internal\rapidocr_onnxruntime\models` 缺失 |
| 点击整体偏移 / 点不中 | 先 `校准工具.exe verify` 复检 | 复检超差 → 重跑映射标定；只有个别按钮点不中 → 跑 UI 落点校准 |
| 机械臂不动 / 连不上 | 串口服务 | 服务被强杀过就 `Restart-Service JxbService -Force`；或 `校准工具.exe home` 归位试试 |
| 截图是歪的 / 尺寸不对 | `config\vision.json` → `capture` 段 | 换取帧源后**所有标定必须重做**（该文件里已注明） |
