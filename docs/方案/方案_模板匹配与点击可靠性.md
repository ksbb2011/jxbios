## 2. A 层：不依赖问题 1，可立即实施

### A1. 阈值体系重构（最关键，今天就在它上面翻车）⭐⭐⭐

**原则**：阈值**不能全局一刀切**，必须按每个模板的**实测得分分布**单独定。

```
阈值 = max(负样本最高分) + 余量(≥0.04)
       且必须 < min(正样本得分) - 余量
若两者冲突（正负样本重叠）→ 说明该模板不可用，需重采或换判据
```

**做法**：
1. 用 `dump_scores.py` / `score_live_templates.py` 对每个模板采集：
   - 正样本（该出现的地方）得分分布
   - 负样本（不该出现的地方）最高分
2. 计算并写入 `templates.json`，同时把**分布数据存档**作为基线
3. 建立**卡线预警**：`正样本最低分 − 阈值 < 0.04` 即报警

**反例警示**：`detail_back` 正样本 0.867、阈值 0.88 → 100% 判不出。
`模板清单.md` 第 9 节"全部对齐 0.88"的要求应**撤销**。

### A2. 模板治理（清理 + 规范）⭐⭐

- **删除 17 个重复素材**（`模板清单.md` 第 8 节已列对照表），避免选错
- **规范命名**：按"页面_元素_变体"命名，`purpose` 必须与图像内容一致
  （`detail_back` → 应改名或改注为"举报+分享组合锚点"）
- **处置 20+ 未标注采集**：识别后回填，或直接归档（避免误用）
- **补齐 ROI**：`roi: null` 的模板逐个人工框定，减少全帧误报与耗时

### A3. 减少"锚点 + 大偏移" ⭐⭐⭐

**原则**：**能直接定位目标，就不用锚点 + 偏移**。

| 场景 | 现在 | 建议 |
|---|---|---|
| 详情返回 | 锚点(379,98) −267px → 箭头 | **直接用返回箭头自身的模板**（已有 `back_arrow_top_left`）或"左上 1/8 区域"布局约束定位 |
| 必须用时 | — | 锚点**尽量靠近目标**（偏移越短越稳），并把偏移写进配置而非代码 |

### A4. 多证据融合 ⭐⭐

- **模板 + OCR 文字 + 布局约束 + 状态机上下文**共同判定
- 例：详情页判定 = `back` 命中 **AND** `share` 命中 **AND** 无"列表底栏"特征
- 例：弹窗判定 = 模板 **OR** OCR 命中标题文字 **OR** 灰蒙版视觉特征（现已是"或"，可加权）

### A5. 点击闭环校验 ⭐⭐⭐

```
点击 → 等待 → 校验状态是否如预期变化
        ├─ 成功 → 继续
        ├─ 未变化 → 换备选点 / 换策略 → 重试（限次）
        └─ 仍失败 → 记录 + 报警 + 上报 GUI
```

**收益**：直接消灭"点了没反应却继续往下跑"的问题（今天详情页返回就是这个现象）。

### A6. 常态化体检 ⭐⭐

- **每次启动**：自检关键模板（桌面图标 / 列表红 Tab / 详情双按钮）能否命中，失败即提示
- **每周**：跑一次全量报表（每个模板命中率 / 平均分 / 卡线风险）
- **卡线自动预警**：正样本最低分逼近阈值时提前告警

## 3. B 层：必须等问题 1 完成后再做

| # | 内容 | 为什么依赖问题 1 |
|---|---|---|
| B1 | **模板 ROI 迁移到"手机屏幕坐标系"** | 需要稳定的摄像头↔屏幕对应关系；迁移后摄像头怎么动都不用重采 |
| B2 | **按行 / 按区域缩小搜索范围** | 需要坐标准确，否则切错行 |

> B 层做完后的终极形态：**模板一次采集、长期有效；设备移动只需重算视觉侧 1 分钟**。

## 6. 风险与注意

| 项 | 说明 |
|---|---|
| **阈值不是越高越好** | 0.88 一刀切已在今天造成事故；阈值必须按实测分布定，留 ≥0.04 余量 |
| **自愈需谨慎** | 自动更新模板可能把"误判帧"写进库 → 建议先做"建议模式"，人工确认后再入库 |
| **清理素材前先备份** | 删除重复素材前确保有归档（`flow/_archive/` 已有 40 张备份） |
| **ROI 迁移是破坏性改动** | B1 需保留回退开关，失败自动降级到现有相机像素 ROI |
| **不要并行改太多** | A1~A6 建议逐项合入并回归，便于定位回退 |
