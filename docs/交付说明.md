## 一、快速开始

### 1. 自检（先确认环境）
```
py -3.11 main.py check
```
通过 = 配置 0 错、模板完整、取帧源与机械臂可用。返回码 0 才可跑。

### 2. 设置路线
```
py -3.11 main.py routes "A路线：苏州-广州" --save
py -3.11 main.py routes "B路线：苏州-广州、中山、揭阳" --save
```
多路线粘贴多行；`--max-stops` 控制每侧最多选几个城市（默认 3）。

### 3. 跑完整流程
```
py -3.11 main.py run                    # 设置路线 → 扫描 → 判定（默认从桌面导航）
py -3.11 main.py run --route D          # 指定跑 D 路线
py -3.11 main.py run --max-run-sec 600  # 限时 10 分钟，到点自动收工输出摘要
py -3.11 main.py run --no-setup         # 跳过路线设置（路线已设好、已在列表页时）
```

### 4. 调试（只读，不动作、不抢单）
```
py -3.11 main.py scan                   # 抓一屏列表，打印切卡 + 字段 + 命中
py -3.11 main.py scan --image xxx.png   # 用截图代替真机
```

## 二、安全开关（`config/runtime.json`）

| 开关 | 当前值 | 语义 |
|---|---|---|
| `dry_run` | **true** | 试运行：全程照跑但**不点抢单**，只记录「会抢/不抢 + 原因」 |
| `review_mode` | **true** | 审核模式：判定合格后**暂停在详情页**等人工确认 |
| `no_pause_test` | **true** | 不停止测试：合格后不暂停、停留 hold 秒自动返回继续扫（配合 dry_run 连跑测试） |
| `development.unknown_pause` | false | 开发模式：遇未知页立即停等人工（开发期铁律）；正式跑前保持 false 启用自动兜底 |

**正式抢单前的切换顺序**：
1. 保持 `dry_run=true` 先跑 1~2 小时，人工核对命中准确率；
2. 确认无误后 `dry_run=false`、`review_mode=false`（或先只关 review_mode 保留人工审核）；
3. `development.unknown_pause` 建议长期保留 true 作安全兜底。
