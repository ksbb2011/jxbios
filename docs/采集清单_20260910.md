# 模板采集清单（2026-09-10 待现场采集）

> 生成自 `config/templates.json` 中所有已禁用（文件缺失）的模板条目。

## 采集方式
```
# 有原 roi 且位置未变：免框选自动裁（推荐，复用旧 roi）
py -3.11 tools/capture_template.py --name <模板名> --from-json

# 无 roi / 位置有变 / 全屏模板：弹窗鼠标框选
py -3.11 tools/capture_template.py --name <模板名> --interactive
```

**采集前准备**：iMouse 投屏全屏铺满、手机亮度拉高、停在对应页面形态。
**目标**：所有重采模板匹配分 ≥0.90（用户要求低于 0.9 的尽量都重采）。

> 优先级说明：P0=列表/核心流程必经；P1=常见分支；P2=偶发/兜底。
