## 2. 分层纪律（`core/__init__.py:3-8`）

```
domain   纯业务规则（不 import 设备/视觉）
vision   只产出"判断结果"，不做动作
flow     编排（状态机 / handler / 动作）
devices  唯一副作用出口（机械臂 / 摄像头 / 服务）
```

> 📌 文档提到 `infra` 层，但**实际无 `core/infra/` 目录**；
> 对应职责分散在 `config_store.py`、`flow/trace.py`、`flow/order_store.py`。

## 3. 各模块职责

### 3.1 `core/config_store.py` —— 唯一配置源

- `ConfigStore`（142）：加载 9 个 section、模板解析、校验、热重载、写回；线程安全（RLock，154）
- `TemplateSpec`（105-139）：模板注册项（逻辑名/path/alts/threshold/roi/kind/purpose/enabled/match_mode）
- `get_store()`（514-519）：进程内共享实例

### 3.2 `core/devices/`

| 模块 | 职责 | 关键 |
|---|---|---|
| `frame_source.py` | 取帧源抽象（Protocol），屏蔽摄像头/采集卡 | `FrameSet`、`FrameSource`、`create_frame_source` |
| `camera.py` | 摄像头采集，**一次采集输出双流** | `Camera` |
| `arm.py` | 机械臂 HTTP 控制；**像素↔机械臂换算的唯一出口** | `RobotArm` |
| `jxb_service.py` | 重启 JxbService 释放串口（需管理员） | `restart_service` |

### 3.3 `core/vision/`

| 模块 | 职责 | 关键 |
|---|---|---|
| `page_state.py` | 11 态判定，全系统唯一判定入口 | `ScreenState`、`PageDetector` |
| `matcher.py` | 多尺度模板匹配 | `MatchResult`、`TemplateMatcher` |
| `ocr.py` | RapidOCR(ONNX CPU)，懒加载 + 全局锁串行 + 帧差去重 | `TextBox`、`OcrEngine` |
| `stable_state.py` | 双帧一致（过渡帧不动手）+ 空屏快检 | `StableDetector`、`has_content` |
| `imgio.py` | 中文路径图片读写 | `imread_unicode` / `imwrite_unicode` |

### 3.4 `core/domain/`（纯业务，不 import 设备/视觉）

| 模块 | 职责 | 关键 |
|---|---|---|
| `orders.py` | 数据模型，全工程单位唯一约定 | `OrderCard`、`OrderDetail`、`Verdict` |
| `rules.py` | 筛选规则引擎 | `RuleEngine` |
| `capacity.py` | 拼单载重余量账本（吨/方分开记账） | `Capacity` |
| `regions.py` | 省→市字典、城市补全、OCR 错字容错 | `RegionStore` |
| `route_plan.py` | 路线文本解析 → 选择步骤；同省分组 | `split_cities`、`group_by_province` |

### 3.5 `core/flow/`

| 模块 | 职责 | 关键 |
|---|---|---|
| `machine.py` | 状态机主循环 + 分发 + 恢复 + 反风控休息 | `FlowMachine` |
| `handlers.py` | 各状态处理器 | `handle_*` |
| `context.py` | 一次运行的全部可变状态（handler↔machine 唯一数据通道） | `FlowContext` |
| `actions.py` | 动作工具箱：取帧/判定/点模板/点文字/滑动/等待 | `ActionKit` |

| `scanner.py` | 列表页扫描：切卡→探字段→过规则→去重 | `ListScanner`、`CardSplitter`、`FieldProbe` |
| `detail.py` | 详情页：读→判→抢/退 | `DetailReader`、`DetailHandler` |
| `city_picker.py` | 城市面板层级钻探选择 | `CityPicker` |

## 4. 关键类速查

### `RobotArm`（`core/devices/arm.py:71`）—— 全部方法持 RLock 串行

| 类别 | 方法 |
|---|---|
| 生命周期 | `open(restart_service=True)`(168) / `close()`(216) / `recover()`(237) / `reload_config()`(108) / `set_frame_size()`(115) |
| 动作 | `move(ax,ay)`(261) / `move_continuous()`(271，滑动专用 delay≈0) / `press(z)`(284) / `release()`(291) / `reset()`(297) / `back_to_home()`(303) |
| 物理键 | `press_back_key()`(331) / `press_home_key()`(337) |
| 坐标 | **`pixel_to_arm(px,py)`(354)** / `arm_to_pixel()`(395) / `point_reachable()`(406) |
| 点击 | `click_pixel()`(414) / `tap()`(439) |

**通信协议**（文件头 3-9 行）：
```
GET ?duankou={COM}&hco=0&daima=0          开端口 → 返回资源号
GET ?duankou=0&hco={id}&daima=X{x}Y{y}    移动
                          daima=Z{z}      下压
                          daima=Z0        抬起
                          daima=X0Y0Z0    复位
                          daima=0         关端口
```
HTTP keep-alive `requests.Session`，连接坏自动重建。

### `Camera`（`core/devices/camera.py:76`）—— 「双流」是什么

| 流 | 分辨率 | 用途 |
|---|---|---|
| `raw` | 960×1280（`capture_resolution`） | **OCR** 与截图留证（识别在原始像素裁剪行上，越清晰越好） |
| `fast` | 480×640（`fast_size`） | **模板匹配、页面判定、快筛**（所有模板按此分辨率采集 → 零重采） |

### `PageDetector`（`core/vision/page_state.py:149`）

`detect()` 固定判定顺序（306-511，详见 `04` 号文档）：
白 Tab → 弹窗 → 详情页 → 城市面板 → 列表页 → 聊天 → 桌面 → OCR 兜底 → UNKNOWN

### `TemplateMatcher`（`core/vision/matcher.py:56`）

- `find()`(215) 单模板（主文件 + 全部 alt 变体取最高分）
- `find_any()`(248) / `find_all()`(264，跨尺度峰值 + NMS) / `score()`(338)
- `match_mode`：`gray`（灰度 NCC，默认）/ `shape`（Canny 边缘，抗颜色极性）
- 尺度 `[0.6,0.75,0.9,1.0,1.15,1.3,1.5]`，`TM_CCOEFF_NORMED`

### `OcrEngine`（`core/vision/ocr.py:91`）

- `ocr()`(163) / `ocr_roi()`(196) / `ocr_dedup()`(214，均值哈希帧差去重)
- 红字判定：`red_ratio()`(266) / `red_text_boxes()`(272) / `city_red_text_boxes()`(282)
- **全局 `_OCR_LOCK`**（25）保证串行；缺 `rapidocr_onnxruntime` 优雅降级返回 `[]`

### `ActionKit`（`core/flow/actions.py:39`）—— handler 操作真机的唯一入口

| 类别 | 方法 |
|---|---|
| 取帧/判定 | `frame()`(106) / `detect()`(122) / `wait_state()`(142) |
| 点击 | `click_point()`(168) / `click_template()`(186) / `click_close_candidate()`(208) / `click_text()`(318) |
| OCR | `ocr_frame()`(234，整屏结果按帧缓存) / `norm_to_raw_roi()`(275) |
| 滑动 | `swipe()`(336，三次贝塞尔 + 绝对时间轴 + ±0.15 抖动) / `swipe_up()`(415) / `swipe_down()`(440) / `swipe_back_gesture()`(452) |
| 物理键 | `press_back()`(476) / `press_home()`(527) |

**三条硬纪律**（文件头 6-10 行）：
1. 点击坐标一律用 **fast 帧**坐标
2. 点完必须**复判**
3. 越界（`screen_roi` + 30px margin）直接拒绝

### `FlowContext`（`core/flow/context.py:30`）—— dataclass

- 依赖：`store/source/arm/kit/regions/rules/capacity/plan/trace/order_store/watchdog`
- 信号：`stop_event`(43) / `pause_event`(50)
- 钩子：`on_scan`(62) / `on_detail`(63)
- 状态：`counters` / `candidate` / `last_card` / `route_setup_pending` / `held_candidate` / `timings` / `first_detail_seen` 等
- 方法：`emit()`(88) / `stop()`(101) / `bump()`(107) / `pause/resume`(125) / `sleep()`(149，可中断) / `limit()`(153)

## 5. GUI（`gui/app.py`）

- 5 个标签页：**运行控制 / 候选订单 / 路线 / 参数 / 日志**
- 只通过 `RobotTask` 装配层与 core 交互（`app.py:770`），不自行 new 设备
- 直接读写 ctx：`ctx.paused` / `ctx.resume()` / `ctx.held_candidate` / `set_review_action("pindan")`
- 写配置：`store.save_section("routes"/"rules"/"runtime", ...)`
- 定时器：`QTimer(1000)` 状态、`QTimer(40)` 相机预览(25fps)、`QTimer(200)` 日志合并
- 开设备放后台线程 `_boot()`（786-798）
- 停止流程（834-873）：置 stop → join(~20s) → `arm.ensure_homed()` 归位 → `task.close()`

> ⚠️ **加载顺序坑**：必须先 `import onnxruntime` 再 `import PyQt5`，否则 DLL 冲突（`app.py:45-52`）。

## 6. 线程 / 并发模型

| 线程 | 位置 | 说明 |
|---|---|---|
| 主流程 | `task.py:361-367` | daemon 线程跑 `machine.run()` |
| 摄像头采集 | `camera.py:213-248` | 名 `cam-capture`，daemon；只有它调 `VideoCapture.read()`；`Condition` + `_latest` 缓存；`read()` 非阻塞取缓存 |
| 轨迹写盘 | `trace.py:51-64,111-124` | daemon；`Queue(maxsize)`；满则丢弃并计数 |
| GUI 开设备 | `app.py:784` | daemon |

**锁**：
- `ConfigStore._lock`（RLock）
- `RobotArm._lock`（RLock）
- `OcrEngine` 全局 `_OCR_LOCK`（Lock）+ 实例锁
- `Camera._cv`（Condition）

> 📌 `TemplateMatcher` 内部无锁（全局部变量），**可并行调用**。

## 7. 打包与部署

- `python -m PyInstaller build.spec --noconfirm` → `dist/RobotPicker/`
- `build.spec` 关键点：
  - `binaries` 显式打包 `C:\Windows\System32\MSVCP140_1.dll`（onnxruntime 静默依赖）
  - **剔除 Qt 自带的 v14.26 旧版 VC++ DLL**（`_BAD_VC` 过滤，71-91 行）
    → 必须用 v14.50；打包后 4 个 DLL 都应是 **14.50.35719.0**
  - `uac_admin=False`（带 manifest 会导致 onnxruntime DLL 初始化失败），提权靠快捷方式
  - `datas`：`config/` `data/templates/` `requirements.txt` `部署说明.txt` + rapidocr 模型
- 生产包位置：`dist_v5/RobotPicker/`（旧包备份 `dist_v5/RobotPicker_bak_*`）
