## 3. 目录解析（`_project_root()`，`config_store.py:26-50`）

按顺序三选一：

1. 环境变量 `ROBOT_PICKER_HOME`（显式指定，安装到别处/多实例时用）
2. **打包运行**（`sys.frozen`）：
   - 优先 **exe 同级目录**下的 `config/`（可写，标定结果与新模板要落盘）
   - 否则退回 `exe同级/_internal/config/`
   - 都没有则返回 exe 目录
3. **源码运行**：`Path(__file__).resolve().parents[1]`（项目根）

派生：`CONFIG_DIR = PROJECT_ROOT/"config"`、`DATA_DIR = PROJECT_ROOT/"data"`、
`TEMPLATE_DIR = DATA_DIR/"templates"`

**标定目录**：`config/calib/<取帧源>__<机型slug>/`，当前 = `camera__iphone_x`
（`calib_dir()`，465-483）

## 5. 热重载

- 主循环每帧 `store.reload_if_changed()`，按 **mtime** 比较 9 个段
- `hardware` 变化 → `arm.reload_config()`（重读标定）
- `"vision" in changed` → 仅当 `source.resolution_changed()` 为真才重建采集流
  （⚠️ 定义了 `REBUILD_CAPTURE_KEYS` 但**实际未使用**，338-339）
- 校验出错时**保留报错但不中断运行**，段名加「(校验告警)」后缀

---

## 6. 校验规则（`validate()`，429-433 / 343-427）

- `hardware.calibration` 各字段长度正确
- `screen_roi_ratio`：`0 <= l < r <= 1` 且 `0 <= t < b <= 1`
- `arm_range.x / .y`：各 2 个数字
- `vision.capture.capture_resolution` 必须与 `roi_calib_size` **同宽高比（3:4）且为整数倍**
- 启用模板的**主文件必须存在**
- 阈值在 0~1；`rules` 非负；`regions.provinces` 非空且为字符串数组
- `strict=True`（GUI 用）时校验失败抛 `ConfigError`

## 8. 改配置的正确流程

1. ☐ 确认程序**没在运行**（否则可能被回写覆盖）
2. ☐ 备份（复制一份 `.bak_YYYYMMDD`）
3. ☐ 改项目根 `config/*.json`
4. ☐ **若改了源码** → 重新 `PyInstaller build.spec`
5. ☐ 若只改配置 → 同步进生产包 `dist_v5/RobotPicker/_internal/config/`
6. ☐ 启动后复核日志里的实际生效值
