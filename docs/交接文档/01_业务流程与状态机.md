## 2. 主循环

**入口**
- CLI：`main.py:198 cmd_run()` → `RobotTask(store)` → `task.open()` → `task.run()`
- GUI：`gui/app.py:826 self.task.start(...)` → `core/flow/task.py:361` 起 **daemon 线程**跑 `run()`

**循环体**：`core/flow/machine.py:92-159 FlowMachine.run()`

```
95  ctx.start_run()

102 帧间隔 loop.frame_interval_sec = 0.35s（runtime.json）
108 while not ctx.stopped:
112   暂停中 → ctx.wait_resume()
116   store 热重载检查
117   取帧；失败 → _recover_source()
121   detect() 判定页面
123   同态连帧计数（same_screen_streak=5 → 卡死告警）
124   watchdog.tick(res)        ← 每帧监护，在 dispatch 之前
135   路线设置挂起 且 在列表态 → setup_routes()（失败 sleep 3s 后重试）
142   _dispatch(fs, res)
143   异常：ArmError→恢复机械臂；FrameSourceError→恢复取帧；其它→bump+sleep 1s
153   记录单轮耗时；_should_rest()/_rest()（反风控休息，当前 enabled=false）
```

**分发**：`machine.py:163-194 _dispatch()`
- `res.pending == True` → **只等下一帧，绝不动手**（165-169）
- `DESKTOP`→`handle_desktop` ／ `HOME_OTHER`→`handle_home_other`
- `LIST_STATES`→`handle_order_list` ／ `DETAIL`→`handle_detail`
- `CITY_STATES`→`handle_city_panel` ／ `DIALOG_STATES`→`handle_dialog`
- `CHAT`→`handle_chat` ／ 其它→`handle_unknown`

## 5. 异常 / 兜底路径

### 5.1 未知页（`handlers.py:361-418`）——严格按序，不可乱跳

1. **静置重判**：`wait_state(..., timeout=2.0)`（366-375）
2. **OCR 认页**：命中「自定义装货点/卸货点」→ 点页签切回省市区网格（381-396）
3. **关闭按钮**：`click_close_candidate()` 全屏取最高分（398-402）
4. **左边缘右滑手势**（404-409）
5. **返回键**（411-413）
6. 连续 ≥3 次（`recover_max`）→ `press_home()` 回桌面 + 留证截图（414-418）

### 5.2 弹窗判定（双信号，`page_state.py:327-359`）

- 主体分 ≥ `dialog.body_high`(0.90) 且非 `dialog_know` → 直判
- 否则需 `body_low`(0.80) **且** 关闭信号（`close_x`/`offline_back`/`page_add_route_back`）≥ `close_confirm`(0.86) 共证

### 5.3 列表到底

`runtime.list_no_more.action`：
- `next_route`（当前值）：`plan.advance()` 切下一条路线；全跑完或 `capacity.exhausted()` → `ctx.stop()`
- `refresh_restart`：刷新后从头再扫，带 30s 冷却（`handlers.py:232-255`）

### 5.4 重试上限汇总

| 项 | 上限 | 位置 |
|---|---|---|
| 取帧源恢复 | 3 | `runtime.json:39` |
| 机械臂恢复 | 3 | `machine.py:252-261` |
| 桌面点击失败 | 3 → 暂停 60s | `runtime.json:36-37` |
| 弹窗连关 | 5 | `runtime.json:38` |
| 同屏连帧告警 | 5 | `runtime.json:40` |
| 路线设置连续失败 | 3 → 停止 | `runtime.json:42` |
| **详情页退出** | z 逐次加深（0/+0.2/+0.4）→ 右滑 ≤2 次 → 按画面升级；连 2 次失败暂停 5s | `detail.py:819-932` |
| 重复点同一张卡 | 落点半径 20px + 指纹相同 + 120s 内 → 跳过 | `task.py:74-113` |

### 5.5 运行监护 Watchdog（`core/flow/watchdog.py`）

- 6 类判据：`log_match` / `counter` / `counter_delta` / `state_dwell` / `stall` / `elapsed`
- `action`：`stop`（默认）/ `warn`
- **只置 `stop_event`，绝不点击**（`_trigger` 263-264）
- `cooldown_sec` 防递归

## 6. 筛选规则（`core/domain/rules.py`，配置 `config/rules.json`）

**判定顺序**：文字排除 → 图色排除 → 车长/车型 → 吨位方数是否超剩余 → 进详情算单价

### 6.1 列表页 `screen_card()`（`rules.py:274-291`）

1. `check_text()`：命中 `exclude_keywords` 即否（词表：`rules.json:41-51`）
2. `check_image()`：命中 `exclude_templates`（= `dianyi_tag`，即"电议"标签）
3. `check_vehicle()`：多值按 `[/|、,，\s]+` 拆分**精确成员匹配**；「不限」放行；车长容错"去小数点再比"；车型容错"子串包含"
4. `check_capacity()`：吨/方比上限；超 `sanity_max_ton`(30)/`sanity_max_m3`(80) → **转人工不算淘汰**

### 6.2 详情页 `check_detail()`（`rules.py:152-186`）

1. 用车长/车型再核一遍
2. `sanity_max_ton/m3` → 转人工
3. `max_load_ton`(10.0) → 淘汰
4. `check_price()`

### 6.3 单价 `check_price()`（`rules.py:238-270`）

```
单价 = round(价格 / 距离km, 2)          # orders.py:88-97
```

| 条件 | 结果 |
|---|---|
| 算不出单价 | **不放行**，转人工 |
| 价格 > 30000 | 转人工 |
| 单价 > 15 | 转人工 |
| 单价 < 2.0 且 `pass_when_below=false` | **淘汰** |

> ⚠️ **距离只能在详情页拿到**——列表卡片上的距离是"距装货点"，**不是运输距离**，不能用于算单价。
> 这是"每个候选都必须进详情"的根本原因，也是提速的最大障碍（见方案文档 2）。

### 6.4 抢单护栏（`detail.py:743-761`）

`rules.price.grab_guard.require_unit_price_above`（当前 null=不限）、
`max_grab_per_hour`（当前 0=不限）、`runtime.dry_run`（当前 **true**=试运行）。

## 7. 两个容易误解的默认行为

1. **`dry_run = true`** → 不会真的点「立即抢单」，只记录。
2. **`review_mode = true`** → 候选合格时**暂停在详情页等人工确认**。

要让程序全自动跑，需要把这两个都关掉（GUI 参数页可改）。
