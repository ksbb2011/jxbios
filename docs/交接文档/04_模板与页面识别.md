# 04 · 模板与页面识别

---

## 1. 模板体系

- 注册表：`config/templates.json`，共 **38 项（启用 35）**
- 图像目录：`data/templates/`（逻辑名 → 相对路径，程序只认逻辑名）
- 每个模板可有多个 `alts` 变体，`find()` 取最高分
- `match_mode`：`gray`（灰度 NCC，默认）/ `shape`（Canny 边缘形状，抗颜色极性）
- 多尺度：`[0.6, 0.75, 0.9, 1.0, 1.15, 1.3, 1.5]`，`TM_CCOEFF_NORMED`

### 字段说明（`TemplateSpec`，`config_store.py:105-139`）

| 字段 | 含义 |
|---|---|
| `path` | 主图相对路径 |
| `alts` | 变体图列表 |
| `threshold` | 显式阈值（有则优先） |
| `threshold_key` | 指向 `thresholds.exceptions[]` |
| `roi` | 归一化搜索窗 `[l,t,r,b]`；**null = 全帧搜索** |
| `kind` | `icon` / `text`（决定默认阈值 0.88 / 0.60） |
| `match_mode` | `gray` / `shape` |
| `purpose` | 用途说明（**容易与实际内容不符，见下**） |
| `enabled` | 是否启用 |

### 🔴 命名陷阱（真实案例）

`detail_back` 的 `purpose` 写着「详情页左上返回箭头」，
但**实际图像是「举报 + 分享」两个图标的组合**（位于画面右侧，roi `[0.661,0.131,0.848,0.199]`）。

它被当成**锚点**用：`press_back()` 用它的中心 **减去 267px** 得到返回箭头位置。
即 `锚点中心(379,98) + offset(-267,5) = (112,103)` = 真实箭头位置。

**教训**：模板的 `purpose` 可能与图像内容不符，**改模板前先打开图看一眼**。

### 阈值解算优先级（`config_store.py:238-255`）

1. `templates.items.<name>.threshold`（显式数字）
2. `thresholds.exceptions[].current`（按 `threshold_key` 匹配）
3. 按 `kind` 取默认：`text` → `text_label_default`(0.60)；其它 → `icon_default`(**0.88**)

## 2. 页面判定顺序（`page_state.py:306-511`）

**固定顺序，不可调换**（前面的会压过后面的）：

| 序 | 判定 | 依据 |
|---|---|---|
| ⓪ | 白色 Tab `source_white` | **最优先，压过弹窗**（321-325） |
| ① | 弹窗 / 异常页 | 双信号：主体分 ≥0.90 直判；否则 ≥0.80 且关闭信号 ≥0.86（327-359） |
| ② | **详情页 DETAIL** | `detail_back` **AND**（`detail_share` OR `dialog_know`）（361-375） |
| ③ | 城市面板 | `filter_clear` 强信号 + confirm（红/浅红）；否则 OCR 文字兜底（377-411） |
| ④ | 列表页 | `source_red` / `back_to_top` / `settle_anchor` 三路 OR；顺带测 `top_visible` 与听单（413-482） |
| ⑤ | 聊天页 | `chat_voice`（484-488） |
| ⑥ | 桌面 | `desktop_ymm_icon` 或 OCR「运满满」（490-500） |
| ⑦ | UNKNOWN 前 | OCR 城市面板兜底（502-509） |
| ⑧ | UNKNOWN | （511） |

补充：
- `ORDER_LIST_NO_MORE`：仅当 `back_to_top` 命中时才用 `_reached_bottom()` 判（193）
- 听单开关：走 `hardware.calibration.tingdan` 的**颜色判据**（461-465），
  ⚠️ 代码里**没有**读 `thresholds.tingdan`
- CLAHE 预处理可选，**默认关闭**（271）

## 3. 阈值体系（`config/thresholds.json`）

| 段 | 当前值 |
|---|---|
| `icon_default` | **0.88** |
| `text_label_default` | 0.60 |
| `detail` | **back 0.82 / share 0.82**（2026-09-08 从 0.86 下调） |
| `list.settle_anchor` | 0.60 |
| `dialog` | `body_high 0.90` / `body_low 0.80` / `close_confirm 0.86` |

### 🔴 "铁律 0.88 一刀切"是有害的（2026-09-08 事故）

`docs/模板清单.md` 第 9 节要求把所有阈值对齐 0.88。但实测：
- `detail_back` 正样本得分 **0.867**
- 阈值 0.88 → **判不出详情页** → 主流程不认为在详情 → 返回时退化成**右滑手势**
- 用户反馈"详情页返回变成了右滑返回"根因在此

**正确做法**：阈值按每个模板的**实测得分分布**单独定，
`阈值 = max(负样本最高分) + 余量(≥0.04)`，并留卡线预警。
详见 `docs/方案_模板匹配与点击可靠性.md`。

## 4. 返回（press_back）三级降级

`core/flow/actions.py:476-525 press_back()`：

1. **锚点 + 偏移**：匹配 `runtime.detail_back.anchor_template`（默认 `detail_back`），
   中心加 `offset`（当前 `[-267, 5]`）→ 点击
2. 失败 → **iOS 左边缘右滑**手势（`swipe_back_gesture()`）
3. 再失败 → 物理返回键（`arm.press_back_key()`）

> ⚠️ 该方法用 **一个 `except Exception` 包住整段**，
> 所以**机械臂通信失败（8082 掉线）也会被报成"返回箭头检测失败，改手势"**——
> 日志具有误导性，排障时要注意看异常原文。
