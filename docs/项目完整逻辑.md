# 项目完整逻辑 · 运满满找单辅助软件

> 更新：2026-09-11 ｜ 本文档记录项目顶层逻辑，供开发对齐与迭代参考。

---

## 一、项目定位

**订单筛选辅助工具**（不是自动抢单机器人）：

- **程序做**：自动扫描列表 → 筛选符合路线/车长/车型/载重/单价条件的订单 → 进详情页判定 → **停在详情页等人工**。
- **人做**：与货主沟通（电话/线上聊天）→ 决策（接单/继续找单/结束换车/拼单）。
- **抢单是人工操作**，程序不自动点"立即抢单"。

---

## 二、完整三层逻辑

### 阶段 1 · 路线策略生成（暂人工，后期 AI）

1. 司机每天联系客服，告知**当前位置**。
2. 客服在地图工具上标注**当前位置 + 目的地**，截图。
3. 截图发给 AI，AI 给出符合要求的 **A/B/C/D 四条路线策略**。
4. （后期）司机/车辆数据入统一数据库表，与路线数据统一管理。

### 阶段 2 · 找单软件（当前开发目标）

1. 导入 4 条路线 + 司机参数（车长/车型/载重/容积）。
2. 客服点「开始」→ 程序自动扫单。
3. 找到符合条件（路线 + 车长 + 车型 + 载重 + 单价）的订单 → 进详情判定 → **暂停等客服**。
4. 客服与货主沟通（电话 / 详情页进线上聊天）。
5. 沟通后分支：
   - **可接单** → 人工接单 → 选「结束换车」（换下一司机/车）或「开始拼单」。
   - **不符合** → 「继续找单」。
6. **拼单流程**：接完一单后若载重/方数仍有剩余，按剩余量继续找单；命中后人工判定。
   - ⚠️ **拼单时订单载重/方数由客服沟通确认后手动重新输入**（订单 OCR 值不一定准，以货主沟通为准，吨和方都要填），用于准确判断能否拼单。

### 阶段 3 · AI 客服（后期，逐步替代人工）

- 人工客服沟通逐步替换为 AI 客服。
- 沟通渠道两种：① 详情页进入线上聊天界面；② 直接「联系货主」电话沟通。

---

## 三、关键约束

- **订单时效性**：列表页扫单越快越准，效率越高。扫单速度与准确率是核心性能指标。
- **数据预留**：司机/车辆数据表（阶段 1/2 共用）需预留结构。
- **拼单余量**：吨与方分别记账，任一归零提示换车；扣减只在真正接单后 commit。
