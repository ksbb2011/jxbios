## 2) 反思 —— 遇到的问题 / 根因 / 是否踩已知坑（对照 docs/交接文档/06）

1. **车型字段 OCR 噪声严重**：`车型=卸/高栏/保/保/温/卸/温/卸/温/温/平/厢/自/卸/自` —— 相邻标签（货主/保温/自卸）被混入。
   → 根因：车型 ROI 过宽 + 单行 OCR 串字。**踩中 06·D3（货物可能写在货主要求里）+ 06·B3（阈值卡线/误识别）**。
2. **单价普遍过低被淘汰**（多数 0.01~0.07，下限 2.0）：距离大概率是「距装货点」而非运输距离。
   → **踩中 06·D2（距离只能在详情页拿，且是距装货点非运输距离）→ 单价失真、真实好单被误杀**。
3. **`source_red` 首刷未命中 warning**：靠 `back_to_top` 兜底（score=1.00）成功。
   → **踩中 06·B3（阈值卡线/模板态不稳）**，依赖兜底而非自身稳定命中。
4. **「连续 5 轮停在 order_list，可能卡住」×2**：滑屏后无新命中，疑列表到底或滑动幅度/方向需调。未触发 stop（仅 warning），属良性。
5. **JxbService 重启失败 warning**（非管理员）：COM4 资源号=900 仍正常，但不重启埋雷 → 对应 06·A4（8082 掉线易被误报）。

## 3) 优化建议

- **车型抽取**：收窄 `card.offsets` 车型 ROI + 文本排除（货主/保温/自卸），或按 06·D3 双路（车型标签行 + 货主要求）抽取。
- **单价/距离**：落实 06·D2，距离改用运输距离；否则好单全被单价下限误杀（当前 detail_rejected=13 多为单价过低）。
- **跨轮去重**：本轮去重已就位，建议加「轨迹哈希」防跨轮重复进详情。
- **可观测性**：`tools/analyze_runs.py` 增「淘汰原因分布」统计，快速定位误杀。
- **反风控拟人**：`idle` 仅 `swipes%20==0` 触发，改为随机概率触发更自然。
- **source_red 模板**：补变体/调阈值，使其不依赖 back_to_top 兜底即稳定命中。
